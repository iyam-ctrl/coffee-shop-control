# Database

Database foundation v0.1 berada di Supabase project `coffee-shop-control`.

Migration aktif:

- `20260916155409_initial_schema_v0_1`

Domain utama:

- business dan stores
- users dan memberships
- products dan categories
- units, ingredients, recipes
- sales dan payments
- inventory, receiving, stock opname, waste
- shifts, cash deposits, expenses
- audit logs

Setiap perubahan schema berikutnya dibuat sebagai migration terpisah dan diverifikasi setelah diterapkan.
